# Skill with me

分享可复用技能的个人合集。本仓库是技能的版本源；本机安装目录中的副本按需同步。

## 技能索引

| 技能 | 用途 |
| --- | --- |
| [speech-coach](skills/speech-coach/SKILL.md) | 分析、起草和改写职场发言，覆盖向上汇报、负责人讲话、项目复盘、技术分享和活动致辞。 |

每个技能独立放在 `skills/<技能名>/` 中，入口为 `SKILL.md`；依赖、适用范围和使用方法以各技能说明为准。

## 安装到 Codex

克隆仓库后，在仓库根目录操作，每次只安装需要的技能。

首次安装 `speech-coach`（目标目录尚不存在时）：

```sh
mkdir -p ~/.codex/skills
cp -R skills/speech-coach ~/.codex/skills/
```

如果 `~/.codex/skills/speech-coach` 已存在，先比较：

```sh
diff -ru ~/.codex/skills/speech-coach skills/speech-coach
```

确认本地修改如何保留后，再同步选定文件；不要直接覆盖已有版本。希望长期保留的修改应先整理回本仓库，再更新安装副本。安装后，在新会话中确认技能可用。

## 案例与维护

新增或更新技能时，同时维护上面的索引，并遵循 [AGENTS.md](AGENTS.md)。只提交本次目标技能及必要的配套文档，不自动收集全部本机技能。

`speech-coach` 的案例均为完全虚构的教学示例，用于展示表达方法，不代表真实人物、组织、会议或业务结果。使用技能不需要访问任何内部文档。

技能可按用户要求分析其提供或授权访问的真实材料；这些材料不会因此成为可公开传播的案例。新增公开案例时使用原创虚构内容，并明确区分示例、建议与事实。
